## Task 2: Comparison Between Open and Closed Source AI Models

| Comparison Point | Open Source / Open-Weight Models | Closed Source Models |
|---|---|---|
| Cost | Many models can be downloaded and run locally, but hardware and maintenance cost money. Example: Llama 2. | Often accessed through paid APIs or subscriptions. Example: GPT-4. |
| Customization | Usually allows more control over deployment and, depending on the license, fine-tuning. Example: Falcon. | Customization is generally limited to the provider's available tools and API. Example: Gemini. |
| Community Support | Often benefits from public developer communities and shared tools. Example: Llama 2. | Primarily supported through the provider's documentation and support channels. Example: GPT-4. |
| Data Privacy | Local deployment can help keep data on your own system, if configured correctly. Example: Llama 2. | Data is processed according to the provider's service and privacy policies. Example: Claude. |
| Update Frequency | Updates depend on the model developers and community. Users may choose when to update. | The provider manages model updates and availability. Example: Gemini. |

**Note:** Open-weight does not always mean fully open source. Model licenses and usage restrictions differ. Privacy also depends on how the model is deployed and configured.

## Task 3: Install Ollama and Run Llama 2 Locally

### Step 1: Install Ollama

Download Ollama for Windows from its official website:

https://ollama.com/download

Install it and open PowerShell or Command Prompt.

### Step 2: Download and Run Llama 2

Run the following command:

```bash
ollama run llama2
```

This command downloads the Llama 2 model if it is not already available and starts an interactive chat session.

### Step 3: Example Output

```text
PS C:\Users\YourName> ollama run llama2

pulling manifest
pulling model layers...
verifying sha256 digest
success

>>> Send a message (/? for help)
```

**Observation:**

Ollama downloads the required Llama 2 model files and starts the model on the local computer. After the model starts, I can enter questions in the terminal and receive AI-generated responses.

*Note: The displayed output is an illustrative example. The actual output and progress messages may differ on your system.*

## Conclusion

Open-weight and closed-source LLMs both have important uses in modern applications. Open-weight models can provide more control over local deployment, while closed-source models often provide convenient access through hosted services and APIs. Ollama makes it possible to download and run supported LLMs locally and interact with them through a terminal.
